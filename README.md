# Business Communications Practice Exams

An interactive, single-page practice tool for Business Communications exams.

- **Exam 1** – Foundations of business communication (Sets A–B)
- **Exam 2** – Chapters 6–9 (Sets A–C)
- Exams 3 and 4 – coming soon

200 multiple-choice questions with instant feedback, explanations, a "retake the ones you missed" mode, optional question shuffling, and best scores saved in your browser.

## Use it

Open `index.html` in any browser. It has no build step and no dependencies; only the fonts load from Google Fonts.

When GitHub Pages is on, the site is live at https://luteron2026.github.io/BusCom/

## Updating

Replace `index.html` with the new version of the page. The question bank is the `DATA` object near the bottom of the file.
